## 📖 О проекте

**LLM Council** — это  веб-приложение, которое превращает процесс получения ответов от искусственного интеллекта в полноценное заседание экспертного совета. Вместо того чтобы полагаться на мнение одной модели, система задействует несколько различных LLM (или ролевых персонажей), заставляя их совместно обсуждать, оценивать и синтезировать лучший ответ.

Ключевая особенность проекта — **трёхэтапный процесс обсуждения с анонимным взаимным рецензированием**. На втором этапе модели оценивают ответы друг друга, не зная авторства (ответы маскируются как "Response A", "Response B" и т.д.). Это предотвращает предвзятость, когда модель могла бы необъективно завысить оценку собственному ответу или ответам "дружественных" архитектур.

Проект решает проблему галлюцинаций и однобокости суждений отдельных нейросетей, предоставляя пользователю взвешенное, критически осмысленное решение, прошедшее проверку "коллективным разумом". Это идеальный инструмент для сложных задач, требующих многогранного анализа, мозгового штурма или проверки фактов.

## ✨ Возможности

*   🤖 **Два уникальных режима работы:**
    *   **Битва моделей (Ensemble):** Один вопрос отправляется разным провайдерам (GPT, Claude, Gemini, Llama и др.) для сравнения подходов.
    *   **Ролевой мозговой штурм (Roleplay):** Вопрос обсуждают цифровые личности (Скептик, Визионер, Перфекционист и др.) внутри одной мощной модели.
*   🕵️ **Анонимное рецензирование:** Модели оценивают ответы вслепую, обеспечивая честность ранжирования.
*   🧠 **Синтез Председателя:** Специальная модель-модератор собирает все аргументы и рейтинги в единый итоговый ответ.
*   🔍 **Полная прозрачность:** Вы видите не только финальный результат, но и исходные ответы, сырые тексты оценок и логику ранжирования.
*   ⚡ **Асинхронная архитектура:** Пар��ллельные запросы ко всем участникам совета для минимизации времени ожидания.
*   🔒 **Локальное хранение:** История диалогов сохраняется локально в JSON-файлах, данные не покидают ваш сервер.
*   🎨 **Удобный UI:** Современный интерфейс с поддержкой Markdown, потоковым выводом и управлением историей чатов.

## 📦 Установка и запуск

### Вариант 1: Docker Compose (Рекомендуется) 🐳

Самый быстрый способ развернуть всё окружение.

1.  **Клонируйте репозиторий и настройте переменные:**
    ```bash
    git clone <repository-url>
    cd llm-council
    cp backend/.env.example backend/.env
    # Отредактируйте backend/.env, добавив ваш OPENROUTER_API_KEY
    ```

2.  **Запустите контейнеры:**
    ```bash
    docker-compose up --build
    ```

3.  **Откройте приложение:**
    Перейдите по адресу [http://localhost:5173](http://localhost:5173)

---

### Вариант 2: Ручная установка 👨‍💻

#### Требования
*   Python 3.10+
*   Node.js 18+ и npm
*   Ключ API от [OpenRouter](https://openrouter.ai/)

#### 1. Настройка бэкенда
```bash
# Создание виртуального окружения
python3 -m venv .venv
source .venv/bin/activate  # Для Windows: .venv\Scripts\activate

# Установка зависимостей
pip install -r backend/requirements.txt

# Настройка конфигурации
cp backend/.env.example backend/.env
# Отредактируйте backend/.env и добавьте ключ API
```

#### 2. Настройка фронтенда
```bash
cd frontend
npm install
cd ..
```

#### 3. Запуск серверов
Вам потребуется два терминала.

**Терминал 1 (Backend):**
```bash
source .venv/bin/activate
python -m backend.main
# Сервер запустится на порту 8001
```

**Терминал 2 (Frontend):**
```bash
cd frontend
npm run dev
# Клиент запустится на порту 5173
```

## 💡 Примеры использования

### Режим "Битва моделей"
Пользователь задает сложный вопрос, например: *"Каковы этические последствия развития сильного ИИ?"*.
1.  **Этап 1:** GPT-4, Claude 3 и Llama 3 дают свои независимые ответы.
2.  **Этап 2:** Каждая модель получает ответы других (анонимно) и ранжирует их по глубине и аргументации.
3.  **Этап 3:** Модель-председатель (например, Gemini) анализирует все доводы и выдает сбалансированное резюме.

### Режим "Ролевой мозговой штурм"
Пользователь спрашивает: *"Стоит ли внедрять четырехдневную рабочую неделю в нашей компании?"*.
Роли (настроенные в `backend/roles.json`):
*   **Скептик:** Укажет на риски падения продуктивности.
*   **Визионер:** Расскажет о росте лояльности и инноваций.
*   **Бухгалтер:** Посчитает экономические потери и выгоды.
*   **HR-директор:** Оценит влияние на найм и удержание кадров.

В итоге вы получите многогранный анализ проблемы
