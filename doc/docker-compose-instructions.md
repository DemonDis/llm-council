# Запуск LLM Council с помощью Docker Compose

## Запустите сборку и запуск контейнеров:
```bash
docker-compose up --build
```

## Остановить контейнеры 
Нажмите `Ctrl+C` в терминале, где запущен `docker-compose`, или выполните команду (из другой вкладки):
```bash
docker-compose down
```

## Запуск в фоновом режиме (daemon)
Чтобы терминал не был занят логами приложения, используйте флаг `-d`:
```bash
docker-compose up -d --build
```

## Просмотр логов
Если вы запустили контейнеры в фоновом режиме, логи можно посмотреть так:
```bash
docker-compose logs -f
```
