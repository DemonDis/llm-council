Ниже — 5 вымышленных профилей для экспериментов с подбором исполнителей, распределением задач и формированием команд. Профили специально сделаны разными по сильным сторонам, стилю работы и ограничениям.

Оценка hard skills: **0–5**.
Оценка soft skills: **1–5**.

# Идеи для экспериментов

## Эксперимент 1. Подбор исполнителя

```md
Есть задача: подготовить план запуска нового внутреннего сервиса.

Выбери наиболее подходящего исполнителя из пяти профилей.
Укажи:

- оценку соответствия от 0 до 100;
- причины выбора;
- риски;
- необходимый уровень контроля;
- кого привлечь в помощь.
```

Ожидаемый основной кандидат: **Ярослав**.

---

## Эксперимент 2. Сбор команды

```md
Нужно подготовить и запустить новый цифровой продукт.

Собери минимальную команду из пяти сотрудников.
Распредели:

- владельца результата;
- аналитика;
- технического исполнителя;
- дизайнера;
- специалиста по качеству.

Укажи зоны ответственности, загрузку и контрольные точки.
```

Возможная команда:

- Ярослав — руководитель;
- Любомира — требования и клиент;
- Милослав — реализация;
- Велимира — UX/UI;
- Радомир — качество.

---

## Эксперимент 3. Работа с неопределённостью

```md
Есть только общая идея продукта, подробных требований нет.
Определи:

1. Кто лучше начнёт работу.
2. Кому дать задачу на исследование.
3. Кто должен подключиться позже.
4. Какие вопросы нужно выяснить.
5. Какой результат получить за первую неделю.
```

Ожидаемые кандидаты на первом этапе: **Ярослав, Любомира и Велимира**.

---

## Эксперимент 4. Быстрый запуск

```md
Нужно получить рабочий результат за 10 дней.
Сравни два варианта:

1. Один Милослав выполняет техническую часть самостоятельно.
2. Милослав работает вместе с Радомиром, а Ярослав координирует процесс.

Сравни сроки, риски, качество и загрузку.
```

---

## Эксперимент 5. Развивающие задачи

```md
Определи для каждого сотрудника одну развивающую задачу,
которая соответствует его сильным сторонам, но развивает слабый навык.

Укажи:

- задачу;
- наставника;
- допустимый уровень риска;
- срок;
- критерий успеха.
```

## Универсальный запрос к ИИ

```md
Используй профили пяти сотрудников и проанализируй задачу ниже.

# Задача

[описание задачи]

# Цель

[ожидаемый результат]

# Срок

[срок]

# Ограничения

- Бюджет:
- Доступные часы:
- Уровень срочности:
- Уровень неопределённости:
- Необходимость общения с клиентом:
- Цена ошибки:

# Нужно определить

1. Кто лучше всего подходит для задачи.
2. Какую команду собрать.
3. Кто будет владельцем результата.
4. Какие задачи дать каждому.
5. Что можно выполнять параллельно.
6. Какие риски существуют.
7. Кто нуждается в наставнике.
8. Кого не стоит назначать и почему.
9. Какой план работы предложить.
10. Как проверить правильность решения после завершения задачи.

Не делай выводов о личности сотрудников. Используй только рабочие навыки,
наблюдаемое поведение, предпочтения и текущую доступность.
```
