# Фронтенд LLM Council

## Установка зависимостей
Перейдите в директорию `frontend` и установите зависимости:
```bash
cd frontend
npm install
```

### Запуск сервера разработки
Для запуска локального сервера Vite:
```bash
npm run dev
```
По умолчанию приложение будет доступно по адресу: http://localhost:5173
