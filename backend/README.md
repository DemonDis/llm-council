# Backend для LLM Council

## Установка и запуск
1. Перейдите в корневую папку проекта:
```bash
cd ..
```

2. Создайте виртуальное окружение, используя Python 3.12:
```bash
python3.12 -m venv .venv
```

3. Активируйте виртуальное окружение:
```bash
source .venv/bin/activate
```

4. Установите зависимости:
```bash
pip install -r requirements.txt
```

5. Создайте конфигурационный файл в папке `backend`:
```bash
cp .env.example .env
```
Отредактируйте `.env`, указав ваш API-ключ и настройки моделей.

6. Запустите сервер (команду нужно выполнять из корня проекта, не из папки backend):
```bash
python -m main
```

Бэкенд будет доступен по адресу: http://localhost:8001
